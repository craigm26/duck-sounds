# The simulator's physics model — what is the robot's and what is ours

`scene.xml` is generated by `build_scene.py` from `robot_walk.xml`, the MJCF
Pollen publishes under Apache-2.0 in
[pollen-robotics/microduck](https://github.com/pollen-robotics/microduck).

## From the robot

- 15 bodies with **measured masses and full inertia tensors**
- 14 hinge joints, their axes and their travel limits
- The site positions (feet, camera, IMUs, mouth tip)
- `alpha_walking.onnx`, the trained policy
- The observation layout, action scale (0.9) and low-pass coefficients, taken
  from `duckkit-constants.json` — exported from DuckKit, whose forward pass is
  checked against onnxruntime to 1e-4

## Ours, because it is not published

Pollen's MJCF has **zero `<geom>` and zero `<actuator>`**: it is kinematics and
mass only, so it cannot touch anything or move itself. To simulate it at all we
added:

| What | Value | Why it is a guess |
|---|---|---|
| Floor | plane, friction 1.0 | Has to exist |
| Soles | boxes 52 × 34 × 12 mm at the model's own foot sites | The real foot shape is not published |
| Actuators | `position`, kp 9.0, kv 0.25, forcerange ±2.5 N·m | The real servo gains are not published |
| Joint damping | 0.06, armature 0.008, frictionloss 0.002 | Not published |

## What that means for the result

Measured over 8 s per case, from the home pose (`node walk.mjs`):

```
stand       moved 0.002 m   speed 0.000 m/s   upright
walk        moved 0.625 m   speed 0.078 m/s   upright
fast        moved 0.800 m   speed 0.100 m/s   upright
turn        moved 0.071 m   speed 0.009 m/s   upright
walk+turn   moved 0.381 m   speed 0.048 m/s   upright
```

It walks and it never falls. But it reaches roughly half the commanded speed,
it drifts sideways, and it will not walk slowly — those are properties of the
actuator model above, not of the Microduck. **A faithful policy in an
approximate body.**

For the robot's actual collision model, see Pollen's own simulator:
<https://huggingface.co/spaces/pollen-robotics/microduck-simulator>. Its assets
carry no licence, so nothing from it is vendored here.

## Running the headless check

```bash
npm install            # mujoco + onnxruntime-node
node walk.mjs          # prints the table above; PASS if it never falls
```

`walk.mjs` imports `../site/duckloop.mjs` — the *same* control loop the browser
runs, so the headless result and the page cannot diverge.
